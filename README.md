# PS5 DualSense → Keyboard Mapper

Map a **PS5 DualSense controller** (USB or Bluetooth) to keyboard keys, so you can drive VLC, YouTube, Spotify, or anything else that responds to keyboard shortcuts — directly from your controller.

Built with [JInput](https://github.com/jinput/jinput) and Java's `java.awt.Robot`.

---

## Features

- Works over **USB and Bluetooth**
- **Auto-repeat while held** — hold a button and the key fires every 150 ms
- **Fully remappable** — edit one constant per button at the top of the file
- **Disable any button** by setting its key to `0`
- Extracts JInput natives automatically on first run
- Silent terminal output (only the mapping banner prints)
- Releases all held keys on exit (no stuck keys)
